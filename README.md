# Portfolio

Personal portfolio site for Neil Patrick Ybañez. Static HTML/CSS/JS, no build step, no framework.

## Structure

- `index.html` - all page content
- `styles.css` - all styling (design tokens at the top)
- `script.js` - mobile nav toggle, active-section nav highlight, footer year
- `assets/` - headshot and favicon

## Colors

- `#fcfbf5` background
- `#1e3602` ink / dark sections
- `#ffec5c` accent

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server, e.g.:

```
npx serve .
```

## Deploy

Static site, deployable anywhere (GitHub Pages, Vercel, Netlify). No environment variables or build step required.
